## Attendee Preparation

1. Bring a laptop (win/mac/linux all okay)  
2. Windows laptop  
   1. Install Keyman Developer ([https\://keyman.com/developer](https://keyman.com/developer)) or `npm install -g @keymanapp/kmc`  
   2. Optionally install Keyman for Windows to test keyboard outside Keyman Developer IDE  
   3. Optionally, install [VS Code](https://code.visualstudio.com/) for more refined XML editing  
3. Linux/mac laptops (or keen Windows users)  
   1. Install node.js ([https\://nodejs.org/](https://nodejs.org/))  
   2. From a terminal, run `npm install -g @keymanapp/kmc`.   
   3. To test keyboard, install Keyman for mac / Linux  
   4. Select your favourite XML editor (e.g. [VS Code](https://code.visualstudio.com/) if you have no preference)  
4. Choose a language for which you would like to build an LDML keyboard, and bring character repertoire and thoughts about layout
